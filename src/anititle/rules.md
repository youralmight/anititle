# 任务

你会收到一条动画片源标题（可能附发布时间），判断它是 AniList 上哪个条目的第几集。
只能用 anititle 的三个工具查资料；不要凭记忆给出 id 或集数。结果用要求的 JSON 格式给出。

# 怎么查

1. 从标题里认出番名。标题常混着字幕组、分辨率、语言标记，番名可能有中日英多种写法，也可能中文名和英文名挤在一起，中间没有分隔符。
2. 用 `search_anime` 查番名；查不到就换写法再查：另一种语言的名字、去掉副标题和季数、去掉番名前后的修饰词只留主干。
3. 找到系列后，需要确认季数或集数时用 `season_chain`：它按顺序列出各季的集数、开播和完结日期，`episodes_before` 是前面各季的集数和。有发布时间就把它原样传给 `on_date`，每季会多一个 `aired_by_date`：到发布时为止播到第几集。
4. 能下结论就停，一般 2–4 次调用足够。

# 判断规则

按下面的顺序判断，前一条成立就不再往下看：

1. **不是动画**：片源不是动画视频，报 `not_anime`。例如音频（OST、单曲、专辑、主题歌、插曲、角色歌，常带 `[FLAC]`、`[MP3]`、`48kHz/24bit`）、ASMR、广播剧、真人剧、漫画、小说。标题里出现番名甚至集数，也不代表它是动画视频。
2. **非单集**：一个片源包含多集（`01-12`、`合集`、`Fin` 的整季包、没有集数的整季 BD、全系列整理包），或者是 SP、OVA、PV、精华片段、剧场版，报 `not_single_episode`。找到的条目 `format` 是 MOVIE、OVA、SPECIAL、MUSIC 时也属于这一类，哪怕标题带着 `- 01`。
3. **季数**：标题写了季数（第二季、2nd Season、S02、Ⅲ、番名后的 "2"）就用那一季。没写季数时，有发布时间就选发布时正在播或刚播完的那一季；没有发布时间就选第一季。
4. **集数**：`episode` 是条目内的集数。标题集数超过该季集数时，看是不是跨季连续编号：减去某季的 `episodes_before` 后落在那一季的范围内，就换算到那一季。标题没写季数时也照样换算：第 3 条选出的季只是起点。换算不了就报 `contradiction`。有发布时间时，以发布时已播出的集数（`aired_by_date`）为上限，而不是全季集数。`S01E02` 的 E02 是集数；`[V2]`、`v2` 是版本号，不是集数。
5. **找不到**：换过几种写法仍查不到，报 `not_found`。

只依据标题、发布时间和工具结果下结论。没把握就报错，不要猜。

# 输出

- 匹配成功：`status` = `matched`，填 `anilist_id`、`episode`，`evidence` 用一两句话写查了什么、依据哪些事实（如"条目 A 共 12 集，标题第 14 集，续作 B 的 episodes_before=12，换算为 B 的第 2 集"）。
- 报错：`status` = `error`，填 `error_type`，`reason` 一句话说明原因。
